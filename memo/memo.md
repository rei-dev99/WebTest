## エンティティの抽出
【user:会員】
- id
- ステータス（仮登録（フォーム登録を行い、リメールの内容に記載の本登録URLをクリックする前の状態）、本登録、退会済み）
- 最終ログイン日時
- 登録日時
- 退会日時

【profile:会員情報】
- id
- 名前
- アカウント名
- メールアドレス
- 登録日時
- 更新日時

【email:メールアドレス】
- id
- メールアドレス
- 登録日時
- 更新日時

【post:投稿】
- id
- 投稿内容
- 投稿作成日時
- 投稿更新日時
- タグ
- スタンプ
- コメント

【comment:返信】
- id
- コメント内容
- コメント作成日時
- コメント更新日時

【stamp:スタンプ】
- id
- スタンプの名前
- スタンプの画像ファイルパス

【tag:タグ】
- id
- タグ
- 登録日時
